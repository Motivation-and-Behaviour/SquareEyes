# Timelapse Software

## Overview

[Timelapse](https://timelapse.ucalgary.ca/) is the software we use to code images.
It's intended for labelling images of animals taken from camera traps, but we've adapted it to work with our wearable camera images.
The next sections describe how to install Timelapse, and how to apply the rules from the coding manual using the software.

## Installation

You can download the Timelapse software from the [Timelapse website](https://timelapse.ucalgary.ca/download/).
You should use the `TimelapseInstaller-PerUser.msi` installer, which will install the software for your user account only and does not require ACU IT support to install.

Old versions of Timelapse required you to run the `Timelapse2.exe` file directly, but the newer versions of Timelapse are installed like any other Windows program and can be run from the Start menu.
