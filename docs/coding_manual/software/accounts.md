# Accounts

## SharePoint

The [Square Eyes SharePoint site](https://myacu.sharepoint.com/sites/SquareEyes) is the only location approved to store image data for this project.
With the exception of temporarily downloading images for coding, you should not store images anywhere else, including on your computer or any other cloud storage service.

All ACU staff have access to SharePoint, but to code images you will need to be added to the [Square Eyes SharePoint site](https://myacu.sharepoint.com/sites/SquareEyes).
The easiest way to check if you have access is to try the link.
If you do not have access, please contact the project officer, Kirsty Bergan, and she will organise access.

## Asana

Asana is the task-management software we use to manage the coding process.
Coding images is a long process, and with multiple coders working on the same project we want to make sure that two people are not coding the same images at the same time.

The Asana project is called [Image Coding](https://app.asana.com/1/653672074038961/project/1205912265356480/list/1205915252345484).
As with SharePoint, the easiest way to check if you have access is to try the link.
