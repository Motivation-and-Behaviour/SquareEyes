# Other Software

## 7-Zip

[7-Zip](https://www.7-zip.org/) is a free and open-source file archiver software that allows you to compress and decompress files and folders.

The zip files created by SharePoint sometimes do not work with the built-in Windows zip file extractor.
If you have issues extracting zip files, you can use 7-Zip to extract the files instead.

### Installation

Installation of 7-Zip requires administrator privileges.
However, it should be pre-installed on all ACU computers.
If your computer does not have 7-Zip installed, please contact ACU IT support to install it for you.
